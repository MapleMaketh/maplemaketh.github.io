RPG DATA GUARD / QUICK START

From the sample
to your own data.

Start with Unity 6000.0.84f1 and a version-controlled copy of your project.

Release candidate guide.

Install the package in your Unity project before following these steps. Public Asset Store release is still pending.

  1. Select the sample profile

    Open Tools > RPG Data Guard. Assign Samples/SampleProfiles/Items.asset from the package to Import profile.

    The sample CSV is Assets/RpgDataGuard/Samples/CSV/items.csv; the output is Assets/GameData/RpgDataGuard/items.

  2. Validate and review

    Click Validate and preview. Expect three Added entries and no errors. Inspect the field values and selected output before continuing.

  3. Apply with backup

    Click Apply with backup. The generated items, catalog and manifest appear in the output directory. Check the results before using the data in your project.

  4. Try a change

    Change the price for sword_01 from 100 to 120 in the sample CSV. Validate again: expect one Modified entry with a price comparison. Apply to update the existing item while retaining its GUID and upgrade reference.

Use the demo

Open Samples/Demo/Demo.unity. Its baked sample data works immediately and is independent of the imported output. To test your import, assign the generated Item_sword_01.asset and ItemCatalog.asset to the Item Demo component.

Save the scene or your own prefab outside the package so your changes are separate from package examples.

The CSV contract

Use UTF-8 CSV with exactly the following seven headers. Headers can be reordered. Quote cells containing commas, quotes or newlines; escape a quote by doubling it.

ColumnRule
idUnique [a-z][a-z0-9_]{0,63}; no trimming or renaming.
display_nameTrimmed length 1–100.
typeWeapon, Armor, Consumable or Material; case-sensitive.
priceInteger 0–2147483647.
max_stackInteger 1–9999; Weapon and Armor require 1.
upgrade_to_idEmpty or another ID in the CSV; no self-reference or cycles.
descriptionUp to 2000 characters.

Blank lines are ignored. Empty and header-only inputs are rejected. Convert legacy encodings such as CP949 to UTF-8 before importing.

Bring your own dataset

Create a profile using Assets > Create > RPG Data Guard > Import Profile, or duplicate the sample outside the package. Use a distinct profile ID and output folder for each dataset. CSV and output paths are relative to the Unity project; output must be beneath Assets and outside Assets/RpgDataGuard.

Missing rows retain their assets and mappings but leave the generated catalog after the preview warning is acknowledged. Changing an ID creates a new item; IDs are identities.

If something interrupts the import

Open History / Recover or Tools > RPG Data Guard Recovery. An unfinished import blocks new imports until recovery is resolved. Recovery refuses to overwrite unexpectedly edited files; preserve the backup and investigate the conflict.

Do not delete unfinished journals to bypass the lock. Transaction files live in .rpgdataguard/backups, outside Assets; keep them private and out of distribution. Keep independent backups and version control.
